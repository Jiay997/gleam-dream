## 一、文档说明与使用方式

### 1.1 读者与使用方式

| 读者 | 使用方式 |
|---|---|
| 前端工程师 | 第二章取 token 建 Tailwind 主题；第三章建组件基线；第四章按页实现布局/组件树/字段/状态；第五章实现复杂交互；第六章遵循工程约定 |
| UI 设计师 | 第二章作为设计稿标注基线；第四章"布局规格"段落作为切图/标注依据 |
| 测试工程师 | 第四章"交互行为清单""状态清单"作为用例来源；第七章核对清单作为验收勾选项 |

### 1.2 强制约定

1. 所有字段名使用 `snake_case`，与 `06_API接口文档.md` 完全一致，前端不做驼峰转换，TS 接口以 `DTO` / `VO` 后缀区分（参见第六章 6.5）。
2. 所有状态枚举取值一律小写蛇形，取值集合不得超出 `00` 第六章"状态枚举总表"。
3. 所有颜色必须取自第二章 token，禁止在业务组件内硬编码十六进制色值。
4. 本文档**不出现深色面板**，全部为浅底深字。
5. 无法确定的数值一律标注【假设待确认】，不以"合适""大约"等模糊词代替。

### 1.3 术语缩写

| 缩写 | 含义 | 对应 00 术语 |
|---|---|---|
| HITL | 人机协同中断 | Human-in-the-Loop |
| QC | 质检 | QC |

| DTO | 出参/入参数据传输对象 | 06 契约 |

|---|---|---|

| `--gd-duration-base` | 200ms | 展开、淡入淡出、Toast |

#### 2.5.2 缓动曲线

| Token | 值 | 用途 |
|---|---|---|
| `--gd-ease-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 通用 |
| `--gd-ease-decelerate` | `cubic-bezier(0, 0, 0.2, 1)` | 进入（抽屉/弹窗） |

| `--gd-ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 落位提示、勾选反馈 |

#### 2.5.3 常见转场

| 场景 | 规格 |
|---|---|
| 抽屉 DrawerPanel | 右侧滑入 300ms `decelerate`，遮罩 `rgba(27,33,48,0.32)` 淡入 200ms |
| Toast | 顶部居中，下沉进入 200ms `decelerate`，停留 3s（错误 5s），上浮退出 200ms `accelerate` |
| Skeleton | 背景 `#F1F3F7` → `#E4E8EF` 线性渐变扫光，周期 1500ms，无限循环 |
| 弹窗 ConfirmDialog | 遮罩淡入 + 缩放 0.96→1，200ms `decelerate` |
| 状态标签变更 | 底色/文字色过渡 120ms `standard` |
| 进度条 | 宽度过渡 300ms `standard`，SSE 更新节流见各页实时更新点 |

#### 2.5.4 无障碍动效

- 尊重 `prefers-reduced-motion: reduce`：关闭扫光、缩放、位移动画，仅保留透明度渐变（120ms）。

| BGM 轨 | `bgm` | 背景音乐片段 | 拖动/裁剪/淡入淡出 | 48px |
| 字幕轨 | `subtitle` | 字幕行 | 拖动（吸附配音）/编辑文本 | 56px |

- 左轨头固定 160px，展示轨名 + 静音/显示开关；时间标尺分辨率随 `zoom` 变化（24/48/96 px/s）。

#### 5.6.2 拖拽与吸附

| 项 | 规格 |
|---|---|
| 拖动 | 片段水平拖动改变 `start_ms`；左右端点拖动改变时长 |
| 吸附 | 默认开启：吸附到相邻片段端点（12px 内）、字幕/配音词边界、播放头、整秒刻度；吸附时显示吸附线（`#6D5AE6` 1px 虚线）+ 目标时间码气泡 |
| 关闭吸附 | 工具栏 SnapToggle 关闭后自由落位 |
| 越界 | 片段不可与相邻片段重叠；重叠时禁止继续拖动并显示红边 |
| 保存 | 松手后 `PATCH /api/v1/timeline-clips/{clip_id}`（节流 300ms 合并多次拖动） |

#### 5.6.3 字幕时间轴对齐

| 项 | 规格 |
|---|---|
| 对齐 | 以配音轨词级边界为准；字幕可吸附到配音词起止 |
| 错位 | 字幕与配音偏差 > 200ms → 字幕片段标黄 + 提示"建议对齐" |
| 编辑 | 双击字幕片段编辑文本，自动重算时长（保持起点）；样式来自 `subtitle_style_id` |
| 硬件安全区 | 竖屏字幕底部保留 15% 安全区，编辑器显示安全区参考线 |

#### 5.6.4 实时预览

| 项 | 规格 |
|---|---|
| 跟随播放 | 播放时预览区随播放头实时切换画面、字幕、混音 |
| 编辑即时反映 | 拖动片段时预览 seek 到片段起点并显示该帧 |
| 音画同步检查 | 每次保存后本地计算 `sync_offset_ms`，≥ 100ms → 片段标黄提示 `70001` |

### 5.7 P20 计费中心（余额卡 / 冻结说明 / 流水 / 套餐）

#### 5.7.1 余额卡

#### 5.7.2 冻结额说明

- 说明文案固定："冻结为生成任务执行前预留的积分，任务成功后按实际消耗结算，失败或审核拒绝将全额解冻返还。单笔冻结 30 分钟未结算自动解冻。"

#### 5.7.3 流水分页与筛选（`transaction_type`）

| 项 | 规格 |

### 6.2 Pinia store 划分

| Store | 职责 | 关键 state |
|---|---|---|
| `useAuthStore` | 登录态、用户信息、token | `token`、`user`、`permissions` |

| `useScriptStore` | 剧本、集、场、行、解析置信度 | `script`、`episodes`、`scenes`、`script_lines`、`confidences` |
| `useAssetStore` | 资产、版本、音色 | `assets`、`asset_versions`、`tts_voices` |
| `useStoryboardStore` | 分镜、镜头、布局 | `storyboard`、`shots`、`layout`、`selection`、`zoom` |

| `useTimelineStore` | 时间线、轨道片段、播放态 | `timeline`、`clips`、`playhead_ms`、`snap` |

- 禁止跨 store 直接改 state，通过 action 交互。
- 列表数据（任务/流水/通知）在 store 内维护分页游标与缓存。

### 6.3 API 层封装

#### 6.3.1 请求拦截

| 项 | 规格 |
|---|---|
| baseURL | `/api/v1` |
| 认证 | 请求头 `Authorization: Bearer <token>`（来自 `useAuthStore`） |
| 幂等 | 写操作（生成/支付/导出）自动生成 `Idempotency-Key`（`crypto.randomUUID()`），缓存 5 分钟内同请求键复用 |
| trace | 记录响应 `request_id` 到日志与 Sentry |

#### 6.3.2 统一错误码处理

| 段位 | 处理 |
|---|---|
| `10001` | 表单校验失败：定位字段红字，Toast 不弹 |
| `10002` | 资源不存在：Toast + 返回上一页 |
| `10003` | 服务内部错误：Toast"服务异常，请稍后重试" |
| `10004` | 限流：Toast"操作过于频繁" |
| `20001` / `20002` | 未登录 / token 过期：清 token → 跳 P01 |
| `20003` | 无权限：Toast"无权限执行该操作" |
| `20004` | 账号封禁：弹 ConfirmDialog（仅确认）+ 登出 |
| `30001` | 积分不足：弹 CostEstimateDialog 充值引导（跳 P20） |
| `30002` | 预算超限：Toast + 提示调整预算 |
| `40001` | 项目状态不允许：Toast 当前状态说明 |
| `40003` | 解析置信度过低：Toast 建议人工校正 |
| `50002` / `50003` | 人脸相似度过低 / 未完成授权：引导 P11 |
| `60001` / `60003` / `60004` / `60005` | 分镜相关：按 Blocker 定位 |
| `70003` | 权益不足：引导升级套餐 |
| `80001`–`80004` | 外部依赖：ErrorRetryBlock 重试 |
| HTTP 401/403 | 同 `20001`/`20003` |
| HTTP 429 | 同 `10004` |

- 错误统一由 `http.ts` 拦截器转换，业务层只处理特定错误（如弹 Dialog）。

#### 6.3.3 幂等键生成

- 生成类请求：`Idempotency-Key = crypto.randomUUID()`，在提交前生成并在同一次用户操作重试时复用；操作成功后清除。

### 6.4 路由守卫与权限指令

| 守卫 | 规格 |
|---|---|
| `beforeEach` 登录守卫 | 无 token 且目标非白名单（P01）→ 跳 P01 并带 `redirect` |
| 路由 meta | `meta.requires_auth`、`meta.project_permission`（`view`/`edit`/`export`）、`meta.team_role` |
| 项目权限守卫 | 进入项目内路由前校验 `useProjectStore.permissions` 是否满足 `meta.project_permission`，不足 → 跳 P05 并 Toast |
| 分期守卫 | `meta.phase = 'P1'` 的路由在未开通时重定向（如平台授权、通知中心） |
| 权限指令 | `v-permission="'export'"`、`v-role="'admin'"`：无权限则移除元素（非隐藏按钮，配合后端二次校验） |
| 焦点管理 | 路由切换后焦点移至页面主标题（`aria-live` 区域播报） |

### 6.5 SSE 封装与重连

| 项 | 规格 |
|---|---|
| 封装 | `useSse(url, handlers)`；封装 `EventSource` |
| 重连 | 断线后指数退避重连：1s/2s/4s/8s/16s，最多 5 次，仍失败降级为 30s 轮询 |
| 事件分发 | 按 `event` 类型分发到对应 store action |
| 节流 | 高频事件（进度）使用 `throttle` 合并（见各页实时更新点） |
| 生命周期 | 页面卸载时 `EventSource.close()`；项目切换重建连接 |
| 心跳 | 服务端 30s 心跳注释行，超过 60s 无心跳主动重连 |
| 认证 | SSE 使用与 HTTP 一致的 token（query 或 header，视后端实现【假设待确认】） |

### 6.6 类型定义组织（DTO / VO）

| 类型 | 位置 | 说明 |
|---|---|---|
| `XxxDTO` | `types/dto/` | 与 06 契约一致，字段 `snake_case`，用于 API 入参/出参 |
| `XxxVO` | `types/vo/` | 前端视图模型，可含派生字段（如 `status_label`、`tone`） |
| 枚举 | `constants/enums.ts` | `as const` 常量 + 中文映射 + 语义色映射 |
| 转换 | `utils/adapters/` | `dtoToVo()` 纯函数，集中做字段派生与格式化 |

- 禁止在组件内直接使用 `any`；未知结构用 `unknown` + 类型守卫。
- 所有枚举映射集中维护，页面不散落 `switch`。

## 附：V2.0 增量规格要点（对齐 PRD V4.0）

1. **P23 生成仪表盘**：计数 chip 六态配色沿用现有状态色 token；ETA 数字 + "波动较大"灰字；SSE 断线重连后全量刷新一次（AC-F5-07-1~2）。
2. **P24 待人工清单**：行内"标记合格"为红框按钮 → 弹窗含声明勾选 + 理由输入（≥5 字）+ "强制通过后不可再以质检不合格为由退款"警示文案（AC-F5-09-1）。
3. **P25 导出历史**：90 天过期记录按钮置灰 + tooltip；"复用参数"预填后参数区高亮（AC-F7-06-1~2）。
4. **P26 授权记录**：撤回按钮红色文字，弹窗要求输入角色名（AC-F3-12-2）。
5. **导出确认页合规区**：AI 标识预览缩略图 + 说明文案"依据《人工智能生成合成内容标识办法》嵌入，不可关闭"；无关闭入口（AC-F7-08-1）。
6. **`gd-cost-note` 组件**：两行式（本次预估 / 已累计消耗），数字加粗、阈值提示为可折叠卡片；资产重抽、批次确认单、合成确认页三处复用。
7. **`gd-fail-card` 组件**：主文案（用户语言）+ 建议动作按钮组 + "详情"折叠区（原始错误码）；未映射码兜底文案固定（AC-F5-02-4）。
