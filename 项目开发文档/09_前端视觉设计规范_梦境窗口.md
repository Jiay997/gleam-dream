## 1. 设计宣言

暖纸办公室是白昼的秩序：米色台面、白纸卡、墨字、发丝线。
夜窗是梦境的开口：暗黑底 + 紫极光，出现在一切"内容之眼"里——封面、镜头缩略图、播放器、图表、AI 灵感。
两域相遇处不划硬线，而是一带柔光雾：夜色像从窗口里晕染到纸面上来。

**三原则**：
1. **窗内才见夜**：暗黑 + 极光只出现在"夜窗"容器（媒体区/预览屏/暗场整页），暖纸面永远保持白昼秩序。暖域禁止裸放暗色块。
2. **交界必有雾**：任何夜窗与纸面的相遇处都有一圈柔光辉光雾（约 16–32px 渐变晕边），禁止 1-2px 硬边框直接拼接。
3. **每屏一焦点**：暖域页面饱和紫只允许一处主按钮或选中态；极光渐变只活在窗内。播放头（紫）是唯一允许跨雾带贯穿两域的元素。

## 2. 配色方案（tokens v6 增量层规划）

| 角色 | 令牌（建议新增/沿用） | 值 | 使用场景 |
|---|---|---|---|
| 暖纸台面 | 沿用 `--gd-neutral-0/canvas` | `#f7f3ec` 系 | 全站底色 + 顶部暖金光池 `gd-desk-light` |
| 纸面卡 | 沿用 `.gd-card` | 白底 + 发丝框 + r16 | 所有内容卡 |
| **夜窗底** | `--gd-window-bg`（v6 新增） | `#0a0a12` | 夜窗媒体区、AI 助手面板、数据图表窗 |
| **极光双辉** | `--gd-aurora-core/dim`（v6 新增） | `#7c5cff` / `#a78bfa` | 仅夜窗内辉光、窗内渐变、暗场整页 |
| **极光渐变** | 沿用 `--gd-grad-primary` | `135deg #8b5cf6→#a78bfa` | 窗内进度条、播放条、暗域主按钮 |
| 暖域主紫 | 沿用 `--gd-primary-500` | `#6d5ae6` 实色 | 主按钮、选中框、激活导航、播放头 |
| **雾光晕边** | `--gd-fog-light/dark`（v6 新增） | 暖白→透明（日侧）/ 紫 α≤0.25→透明（夜侧） | 夜窗边缘、雾带交界 |
| 语义色 | 沿用暖域四色 + strong 档 | 已通过 | 已支付/渲染中/失败/草稿胶囊 |
| 语义色（暗窗内） | 沿用 `--gd-*-bright` | `#5eead4` 等 | 夜窗内状态文字 |

**色量纪律**：暖纸面 = 白纸 + 墨字 + 发丝线 + 一处实色紫；夜窗内 = 黑 + 极光 + 玻璃白。全页极光面积 ≤ 内容媒体区总面积，禁止把极光用到纸面文字或图标上。

## 3. 字体（全部沿用 08 号规范，不变）

- 正文：PingFang SC → HarmonyOS Sans SC → Microsoft YaHei；刊头/卡片题：Noto Serif SC 衬线；数字/时间码：DIN（`.gd-num`）。
- 字阶：masthead-lg 40 / masthead 34 / display 24 / title 16 / 正文 14 / caption 12 / micro 11；字重 400/500/600。
- 刊头左侧 24px 紫短段（PageHeader 现状）保留。

## 4. 圆角 / 阴影 / 间距（沿用 + 两处新增）

- 圆角：控件 6 / 卡片 16 / 弹窗 18 / 播放器外框 22 / 胶囊 full —— 不变。
- 阴影：卡片默认无（分层靠底色差 + 发丝线）；hover 抬升 shadow-2 —— 不变。紫 bloom 仍仅限暗域/窗内。
- **新增**：`--gd-shadow-window`（v6）：`0 0 0 1px rgba(255,255,255,.06) inset, 0 8px 40px rgba(10,10,18,.35)`——夜窗内阴影，制造"窗口凹陷"感。
- 间距：Tailwind 刻度不变；夜窗内边距 12–16px；雾带高度 24–28px。

## 5. 页面结构与布局

### 5.1 全局壳层（不变）
AppShell：全局侧栏 240 暖米 + TopBar 64 + 内容区（`gd-desk-light` 暖光池）+ StatusBar 32 + 助手面板 320。响应式断点同 08 号规范。

### 5.2 创作台 / 内容墙（nd2a）
非对称 Bento 不变；**所有项目卡封面区改为夜窗**：暗黑底 + 极光 + 雾晕边，hero 卡夜窗更大更亮；新建卡 = 虚线发丝框 + 紫加号（不变）。

### 5.3 编辑器双域（nd2b/nd2c/nd2d）
```
┌──────────────────────────────────┐
│ 夜域：预览屏 / 夜窗 AI 面板          │ ← #0e0f13 舞台 + 极光
├── 雾带交界 .gd-fog-junction ──────┤ ← 24-28px 暖雾+紫微光，无硬线
│ 暖纸域：稿纸 / 分镜条 / 时间线       │ ← 纸面 + 白卡
└──────────────────────────────────┘
```
- **雾带**（替代原 2px 墨线 `.gd-junction`）：暖白雾从纸侧升起、紫微光（α≤0.2）从夜侧渗出，中央最浓、两端渐隐；横竖双态。
- 紫播放头垂直贯穿两域，是唯一跨域元素（现播放头语言保留）。
- 分镜画布：镜头卡 = 白纸卡 + 夜窗缩略图（雾晕边）+ DIN 镜号 + 状态胶囊；选中 = 2px `#6d5ae6` 外框 + 柔紫 ring；拖拽 = 抬升 shadow-3；卡片连线 = 墨发丝线 + 紫箭头。
- 脚本编辑器：稿纸卡（横线纹）+ 章节点轨 + 紫 caret；右侧 AI 助手面板整块为夜窗（极光顶部 + 玻璃气泡）。

### 5.4 暗场整页（渲染任务中心 / 登录注册）
- 登录/注册：**不动**（AuthPanel v4 终稿）。
- 渲染任务中心：维持暗场整页，但把辉光刊头/玻璃卡与登录页语言对齐（已是现状），底部表格区与暖域之间加雾带过渡。

### 5.5 工具页深层（nd2f）
PageHeader 体系不变；新增两种夜窗用法：**统计卡内嵌小夜窗**（DIN 数字 + 迷你极光趋势）与**数据图表夜窗**（暗底 + 极光柱线图 + 暖白 DIN 轴标 + 玻璃图例）；表格仍为纸面发丝行。

### 5.6 弹窗 / 抽屉（nd2e）
纸面弹窗 r18 + shadow-4 不变；弹窗内的"预览/封面"类内容用夜窗呈现；步骤指示 = 紫实心当前步 + 绿已完成 + 发丝空心未来步。

## 6. 核心组件与状态（对照 nd2h 规范板）

### 6.1 新组件：夜窗 `.gd-night-window`（v6 核心）
- 结构：容器 r16 + 内层 `#0a0a12` + 顶部极光辉光（radial，#7c5cff 核心/#a78bfa 外圈，多档渐隐防切线）+ 内容（媒体/图表/玻璃气泡）。
- 雾晕边：容器外圈 `box-shadow: 0 0 24px rgba(124,92,255,.18), 0 0 48px rgba(196,190,226,.12)` + 内侧 1px 白 0.06 线；**不用 backdrop-filter**（性能），雾用多层 box-shadow/radial-gradient 实现。
- 变体：`-sm`（缩略图/统计卡内，雾边收窄 16px）、`-chart`（图表窗）、`-panel`（AI 面板整块）。
- reduced-motion：极光静态，不做常驻循环动画（延续登录页纪律）。

### 6.2 沿用组件状态（值不变，仅列验收点）
- 按钮：primary `#6d5ae6`（hover 600/active 700+下压）；暗域/窗内主按钮 = 极光渐变 + bloom。
- 输入域：36px r6 发丝框；focus 紫框 + 3px ring；invalid 玫红框 + 下方错误文案；disabled 凹陷。
- 卡片：默认白纸无阴影；hover 抬升 + 强描边；选中 2px 紫框 + focus ring（分镜卡同款）。
- 状态胶囊：full 圆；浅底彩字（已支付 mint / 渲染中 amber / 失败 soft red / 草稿灰）；窗内 = 彩底 α + bright 字。
- 进度：暖域 8% 深轨 + 紫实色；窗内白 0.10 轨 + 极光渐变 + 端点辉光点。
- Toast 白 pill r12 / 弹窗 r18 / 空状态虚线框 + 极光光斑（现有 `gd-empty-aurora` 与夜窗语言天然一致，保留）。

## 7. 交互与动效（沿用 08 号三档纪律）

- 150/200/300ms；缓动 `--gd-ease-out/standard`；入场只动 transform 不 gate opacity；禁止 scroll 自研动效与常驻循环动画。
- **新增雾带过渡**：路由在"暖页↔暗页"之间切换时，雾带以 opacity 200ms 淡入（只动 transform/opacity）。
- 夜窗 hover：雾边微扩（box-shadow 第一档 24px→32px，150ms）+ 媒体亮度 +4%，不缩放。

## 8. 实施范围与验收

**批次 A（确认后首轮）**：tokens v6 增量层（window-bg/aurora/fog/shadow-window）→ `.gd-night-window` + `.gd-fog-junction` 组件层 → 创作台 Bento 封面夜窗化 → PageHeader 体系复核。
**批次 B**：脚本编辑器（稿纸 + 夜窗 AI 面板 + 雾带）、后期编辑器（雾带替换墨线）、分镜画布（夜窗镜头卡 + 紫选中框）。
**批次 C**：预览/终审（雾带 + 纸面审核栏）、工具页深层（图表夜窗）、渲染中心雾带过渡。
**验收标准**：`npm run build` 通过；dev 实测功能零回归；每屏饱和紫焦点 ≤ 1；夜窗外纸面无暗色裸块；所有夜窗边缘有雾晕无硬边；`prefers-reduced-motion` 全静止；暗域文字 ≥ AA。
