# 08 前端视觉设计规范 ·「纸上放映厅」

> 版本：v1.0（2026-10-13）
> 定位：全站前端视觉重构的设计契约。方向三「纸上放映厅」：外面是制片办公室（暖纸域），里面是放映厅（暗场域）。
> 效果图基准：`vibe_images/p1-overview-refined`、`p2-editor-dualzone`、`p3-render-center-dark`、`s1-component-states`、`s2-feedback-states`。
> 实施纪律：本报告只做**增量层**（tokens.css v5），不改动既有数值契约；重构不改任何业务逻辑、路由、接口与表单字段名。

---

## 1. 整体视觉风格

### 1.1 设计宣言

全站分两个"曝光域"，共享同一套品牌语言：

- **暖纸域（制片办公室）**：暖米台面上一叠白纸，发丝线分区，衬线刊头，墨色文字。凡"写稿子、管事务"的页面都属于这里。
- **暗场域（放映厅）**：深黑舞台 + 紫辉光 + 玻璃浮层 + 亮紫渐变。凡"看片子、等渲染"的场景（播放器、分镜预览、渲染任务中心、登录/注册）都属于这里。

品牌紫是两个域之间唯一的连续色：暖域用深档 `#6d5ae6`（实色），暗域用亮档 `#8b5cf6→#a78bfa`（渐变）。**每一屏最多一处饱和焦点**。

### 1.2 配色方案

| 角色 | 令牌 | 值 | 使用场景 |
|---|---|---|---|
| **主色（暖域）** | `--gd-primary-500/600` | `#6d5ae6` / `#5643cc` | 主按钮实色、激活指示、进度条、focus ring。仅在"可以行动的地方"出现 |
| **主色（暗域）** | `--gd-primary-400` + 渐变 | `#8f7ef2`；`linear-gradient(135deg,#8b5cf6,#a78bfa)` | 暗域主按钮、辉光刊头、进度条、播放头光晕 |
| **辅助色（暖域）** | `--gd-sidebar-active-bg` 等 | `#e9e2f9` 淡紫雾 | 仅限导航激活块、subtle 按钮底，禁止当页面背景 |
| **辅助色（暗域）** | `--gd-aurora-*`（v5 新增） | `#7c5cff` / `#a78bfa` | 辉光 bloom、玻璃卡内极光点缀。禁止用于正文文字 |
| **中性色（暖域）** | `--gd-neutral-0~900` | 暖米 `#f7f3ec` 台面 → 墨 `#17161a` | 台面/纸面/发丝线/文字四层，纪律见 tokens.css 注释 |
| **中性色（暗域）** | `--gd-player-*` + v5 增量 | 舞台 `#0e0f13`、面板 `#17191f`、文字 `#e8e7e4`、次要 `#c9c8c4` | 暗场域全套 |
| **语义色（暖域）** | success/warning/danger/info | 维持现有四色 + strong 档 | 浅底 chip：前景用 strong 档过 AA |
| **语义色（暗域）** | `--gd-*-bright`（v5 扩齐） | success-bright `#5eead4`、warning-bright `#fcd34d`、info-bright `#93c5fd`、danger-bright `#ff9ba0` | 暗底状态胶囊/文字，禁用原深档前景 |

**色量纪律**：暖域页面 = 白纸 + 墨字 + 发丝线，紫色只出现在 1 个主按钮 + 激活指示 + 进度条；暗域页面 = 黑场 + 玻璃 + 一条紫渐变。

### 1.3 字体

| 角色 | 字体族 | 说明 |
|---|---|---|
| 正文/UI | PingFang SC → HarmonyOS Sans SC → Microsoft YaHei（`--gd-font-sans`） | 不下载 Web 字体 |
| 刊头/卡片题 | Noto Serif SC → Songti SC → SimSun（`--gd-font-serif`） | 仅页面刊头、内容墙 hero 题、品牌区；暖域墨色，暗域暖白+辉光 |
| 数字/时间码 | DIN Alternate（`--gd-font-num`） | 金额、进度、时间码、镜号，一律 `.gd-num` |
| 代码 | JetBrains Mono（`--gd-font-mono`） | 仅代码块 |

**字号层级**（沿用 Tailwind 语义字阶，不新增档位）：

| 层级 | 档位 | 字号/行高 | 用途 |
|---|---|---|---|
| 首页刊头 | `masthead-lg` | 40px/1.15 衬线 600 | 内容墙、工作台 |
| 项目域刊头 | `masthead` | 34px/1.2 衬线 600 | 项目域页面 |
| 工具页标题 | `display` | 24px/1.3 衬线 600 | 设置/计费等 |
| 区块/弹窗题 | `title` | 16px/1.45 600 | 卡片题、面板题 |
| 正文 | 默认 | 14px/1.65 | 全站正文 |
| 导语 | `lede` | 15px/1.7 | 刊头下的一句话 |
| 标签/表头 | `caption` | 12px/1.5 | 字段标签、表头 |
| 角标 | `micro` | 11px/1.4 | 仅数字角标 |

字重三档：400 / 500 / 600（中文不用 700）。标题字距 -0.01 ~ -0.025em。

### 1.4 圆角（形状一致性锁）

| 档 | 值 | 用途 |
|---|---|---|
| sm/md | 6px | 交互控件（按钮/输入框/小徽章） |
| lg | 16px | 卡片/面板/暗域玻璃行 |
| xl | 18px | 弹窗 |
| 2xl | 22px | 播放器外框/空状态底 |
| full | 9999px | 状态胶囊/搜索框/头像/进度条/时间线轨道 |

暗域玻璃行与暖域纸卡同为 16px——两个域共享同一形状语言。

### 1.5 阴影（材质即光影）

| 档 | 值 | 用途 |
|---|---|---|
| shadow-0 | none | 卡片默认（分层靠底色差+发丝线） |
| shadow-1/2 | 暖调 1-2px | hover 抬升、浮层 |
| shadow-3/4 | 暖调大影 | 弹窗、抽屉 |
| `--gd-shadow-bloom`（v5 新增） | `0 8px 30px rgba(124,92,255,.20), 0 2px 8px rgba(124,92,255,.14)` | 暗域主按钮、暗域 hover 行、辉光元素。**紫 bloom 只存在于暗域**，暖域禁止 |

### 1.6 间距

唯一来源为 Tailwind 原生刻度：节奏档 4/8/12/16/20/24/32/40/48/64（容器、区块、栅格）；密集档 2/6/10/14（胶囊内距、图标与文字紧邻）。
基准节奏：页面内容区 `p-6 lg:p-8`、卡片内距 `p-6`、区块间距 `mb-8`、栅格 `gap-5`、暗域行间距 28px（对齐登录页域间距）。

## 2. 页面结构与布局

### 2.1 全局壳层（AppShell）

```
┌──────┬──────────────────────────────────────────┐
│      │ TopBar 64px（刊头档 72px）                  │
│ 全局  ├──────────────────────────────────────────┤
│ 导航  │ ProjectSidebar（项目域时）                 │
│ 240px├─────────────────────────────┬────────────┤
│      │ 主内容区（overflow-y-auto）   │ AI 助手面板 │
│      │  max-w-1600 居中             │ 320px 可收起│
│      ├─────────────────────────────┴────────────┤
│      │ StatusBar 32px                            │
└──────┴──────────────────────────────────────────┘
```

- 侧栏 240px 暖米（`--gd-sidebar-bg`）+ 发丝线分区；激活项 = 淡紫块 + 紫图标紫字 + 右端紫色短横胶囊。
- **v5 新增 · 暖光光池**：内容区顶部一层固定装饰（radial，暖金 α≈0.05，高 ~320px，pointer-events-none），给台面一个光源方向。所有暖域页面共享，不逐页实现。
- 响应式：<1024px 侧栏转覆盖抽屉；<1280px 收起助手面板。

### 2.2 暖域页面骨架（工具页/表单页）

```
PageHeader（衬线刊头 + 导语 + 发丝线[左端24px紫短段]）
  └─ 内容列（content-xs/sm/md/lg 版心档）
       └─ gd-card / gd-card-field / 密集列表
```

### 2.3 内容墙（ProjectsView · 非对称 Bento）

```
刊头（masthead-lg + 过滤工具行）
┬──────────────┬───────┬───────┐
│ hero 卡(2列,   │ 卡 │ 卡 │   ← 首行 1+2
│ 行高×2, 衬线题)│   │   │
├───────┬───────┼───────┴───────┤
│ 卡 │ 卡 │ 新建卡(虚线)  │   ← 次行 2+1，含空态卡
┴───────┴───────┴───────────────┘
```

- hero 卡：跨 2 列 2 行，封面 + 衬线大题（`title` 档以上）+ 完整进度行；小卡维持现规格。
- 新建卡 = 空状态卡：虚线发丝框 + 紫加号，与 EmptyState 同语言。
- 封面：沿用 `.gd-cover-*` / `.gd-cover-img`（白 scrim 保 AA），hero 卡 scrim 加深一档。

### 2.4 编辑器双域（分镜/脚本/后期）

```
┌──────────────────────────────────┐
│ 暗场域：预览屏 + 玻璃控制条 + bloom │ ← stage（#0e0f13 + 暗角）
├── 2px 墨线交界（.gd-junction）────┤
│ 暖纸域：分镜条 / 稿纸 / 时间线      │ ← canvas/paper
└──────────────────────────────────┘
```

- 交界 = 2px `--gd-neutral-900` 线；播放头（`--gd-playhead`）垂直贯穿两域，是"放映进度"的缝合线。
- 暗域内浮层用 `--gd-player-panel` + 发丝 `rgba(255,255,255,0.08)`；控制条玻璃化（blur + 白 0.05）。

### 2.5 暗场域整页（渲染任务中心 / 登录注册）

```
辉光刊头（衬线暖白 + 三层紫辉光）+ 副标题 #8a8a95
  └─ 玻璃任务行列表（白0.05 + blur32 + 边框白0.12 + r16，行距28px）
       每行：缩略图 + 题(暖白) + DIN 数据(player-hint) + 紫渐变进度条 + bright 状态胶囊
```

## 3. 核心组件清单（状态 × 样式）

### 3.1 按钮 AppButton

| 变体 | 默认 | hover | active | disabled/loading |
|---|---|---|---|---|
| primary | `bg-primary-500` 白字 + shadow-gd-1 | `bg-primary-600` | `bg-primary-700` + 下压 1px | opacity .45 + 禁点 |
| subtle | `bg-primary-50` 紫字 | `bg-primary-100` | `bg-primary-200` | 同上 |
| secondary | 白底发丝框 | `bg-surface-canvas` + 强描边 | 压色 state-active | 同上 |
| danger / ghost / text | 维持现状 | — | — | 同上 |
| **暗域档（v5）**：暗场页面内主按钮换 `--gd-grad-primary` 渐变 + `--gd-shadow-bloom`（经 `.gd-btn-bright` 工具类叠加，不改 AppButton API） | | | | |

尺寸：sm 28 / md 36 / lg 44，圆角 6px（暗域主按钮可用 r16 胶囊形态）。焦点环：2px `primary-500` outline（全局 ：focus-visible）。

### 3.2 卡片

| 类 | 默认 | hover（interactive） | 选中 |
|---|---|---|---|
| `.gd-card` | 白底 + 发丝框 + 无阴影 | 抬升 1px + shadow-2 + 强描边 | 2px primary-500 边 + `--gd-focus-ring` |
| `.gd-card-field` | 白底无框 | 抬升 2px + shadow-2 | 同上 |
| `.gd-card-dark`（v5 新增） | 白0.05 + blur32 + 白0.12框 + r16 | 抬升 2px + shadow-bloom + 边框白0.2 | 紫亮框 + bloom |

### 3.3 导航

- 全局侧栏：未激活 = 墨字无底；hover = `--gd-state-hover` 压色；激活 = 淡紫块 + 紫字 + 右端短横。
- 项目侧栏 / 编辑器轨道：维持面板令牌；激活项加左缘 2px 紫条（如现状）。

### 3.4 表单

- `.gd-field`：36px、r6、发丝框；hover 强描边；focus 紫框 + 3px ring；disabled 凹陷底 + 禁用字色；invalid 玫红框 + 危险 ring，错误文案在字段下方。
- `.gd-field-dark`：暗域同形变体（已存在，扩展到渲染中心等暗域表单）。
- 标签在上方（caption 档），placeholder ≠ 标签。

### 3.5 弹窗 / 抽屉 / Toast / 空状态 / 骨架

| 组件 | 规格 |
|---|---|
| Modal | 白纸面板 r18 + shadow-4；遮罩 `--gd-overlay`（暖黑40%）；入场：scale .97→1 + 淡入 200ms |
| DrawerPanel | 右侧滑入 300ms ease-out；遮罩同上 |
| Toast | 白 pill r12 + 发丝框 + shadow-2；成功=绿 icon、警示=玫红、反白型=neutral-900 底；入场：底部 8px 滑入 + 淡入；z-toast=100 |
| EmptyState | 极光渐变光斑（品牌极光语言）+ 墨题 + 次要文案 + 可选主按钮；容器虚线发丝框 |
| LoadingSkeleton | `.gd-skeleton` 形状匹配最终布局；暖灰扫光（现状保留） |
| StatusTag | 全圆 pill；浅底=彩底+strong 字；暗底=彩底(α)+bright 字（v5） |

### 3.6 进度条 / 播放头

- 暖域：8% 中性深轨道（`--gd-progress-track`）+ primary-500 实色填充。
- 暗域：白 0.10 轨道 + `--gd-grad-primary` 渐变填充 + 端点微 bloom。
- 播放头 `--gd-playhead` 贯穿暗/暖两域（见 2.4）。

## 4. 交互与动效

**三档时长**：150ms（微反馈）/ 200ms（常规过渡）/ 300ms（大型进出）。缓动：`--gd-ease-out`（进出）、`--gd-ease-standard`（状态）。

| 场景 | 效果 | 约束 |
|---|---|---|
| 路由切换 | 淡入 + 上移 4px（现有 gd-page） | out-in 模式，不 gate 功能性内容 |
| 卡片 hover | 抬升 + 阴影/描边（transform+opacity only） | 150ms |
| 弹窗/抽屉 | scale/translate + 淡入 | 200/300ms |
| Toast | 底部滑入 + 淡入 | 200ms |
| 骨架扫光 | translateX 循环 | 数据到达即卸载 |
| 暗域辉光 | 静态 bloom，**不做常驻循环动画** | 登录页经验：装饰动效克制 |
| reduced-motion | 全部动画/过渡降为 0.01ms（全局规则已有） | 强制 |

硬规则：功能性内容入场动画**只动 transform，不得 gate opacity**；禁止 `window.addEventListener('scroll')` 自研动效。

## 5. 响应式适配

| 断点 | 策略 |
|---|---|
| ≥1280（桌面基准） | 全局布局完整呈现：侧栏 240 + 内容 + 助手 320 |
| 1024–1279 | 助手面板自动收起；内容墙 3 列 → 保持 |
| <1024（平板竖屏） | 全局侧栏转覆盖抽屉（汉堡唤起）；内容墙 2 列；编辑器右轨转抽屉/堆叠；双域编辑器上下占比改为预览 40% |
| <768（移动端） | 内容墙 1 列；TopBar 隐藏搜索；表格页横向滚动；弹窗改近全屏（inset 16px）；触控目标 ≥44px |

移动端折叠必须逐节显式声明（禁止依赖"Tailwind 会兜底"）；画布/时间线类页面在 <768 给只读降级提示而非强行压缩。

## 6. 实施范围与验收

**第一批（本轮）**：tokens v5 增量层 → 全局光池 → PageHeader 刊头紫短段 → EmptyState 极光化 → ProjectsView 非对称 Bento → RenderTaskCenterView 暗场化 → StoryboardCanvasView 交界线与暗域玻璃化。
**后续批次**（同规范逐页推进）：脚本/后期编辑器、资产墙、分发、计费、团队、设置、通知。

**验收标准**：`npm run build` 通过；dev 实测各页面渲染与重构前功能一致（导航、表单、弹窗、状态流转不回归）；暗域文字对比 ≥ AA；`prefers-reduced-motion` 下无动画；每屏饱和紫色 ≤ 一处焦点。
