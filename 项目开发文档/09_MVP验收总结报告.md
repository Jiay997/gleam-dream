## 一、验收结论

MVP 阶段目标——"单用户在 Web 端从一句话创意走到下载成片"——**已在 Sandbox 环境下完整达成**：

- 端到端全旅程 12 步冒烟测试全部 PASS（注册→充值→建项目→剧本生成→HITL-1→资产→HITL-2→分镜→HITL-3→批量生成→后期→HITL-4→导出→通知→越权走查）；
- 后端 pytest 57/57 全绿，前端 TS strict 构建零错误；
- 桌面一键启停脚本 start/stop/status 实测通过，进程零残留；
- 02 文档定义的 11 业务域 56 张表全部建成并完成种子数据。

**保留项**：媒体生成（图像/视频/TTS/BGM）与支付/短信/微信/平台分发/内容审核均为 Sandbox Stub；LangGraph 编排仅落地编剧子图。上述内容不阻塞 MVP 功能验收，但构成上线前必须完成的工作（见第七、八章）。

## 五、与设计文档的已知偏差（均已记录并评审）

| # | 偏差 | 设计基线 | 实际实现 | 定性 |
|---|---|---|---|---|
| 1 | 任务队列 | Celery 5.4 + Redis（6 队列） | asyncio 内存执行器模拟队列语义 | spec 允许的裁剪（本机无 Redis，单机一键启停要求） |
| 2 | 向量检索 | PostgreSQL 16 + pgvector | DOUBLE PRECISION[] + 应用层余弦相似度 | spec 允许的降级（量级小满足 QC 比对） |
| 3 | 事件总线 | Redis Stream / Pub-Sub | 进程内 EventBus（心跳+补偿保留） | spec 允许的降级 |
| 4 | 对象存储 | S3 兼容 OSS + 预签名直传 | 本地磁盘 `backend/storage/` 经 `/files` 下发 | Sandbox 替代 |
| 5 | LangGraph 编排 | 主图 + 六子图全图化 | 仅编剧子图 + HITL-1 走图编排；资产/分镜由域服务同步管线替代（Task 6a 完成，6b 调整） | **架构偏差，需后续决策**（见 7.1） |
| 6 | HITL-3/4 | interrupt() 图恢复 | 分镜/后期域 decide 接口实现，审批单双写语义一致 | 等价实现 |
| 7 | admin 管理后台 | 应用层 13 模块之一 | 专用端点裁剪为 P2，只读能力并入既有查询端点 | 范围裁剪 |
| 8 | 端口 | 后端 8000 / 前端 5173 | 后端 8100 / 前端 5175 | 环境冲突规避，无实质影响 |

## 六、Sandbox 声明（验收有效性边界）

以下能力在本次验收中为**演示占位/模拟实现**，功能链路与数据流转已验证，但**不含真实外部服务交互**：

| 能力 | 当前实现 | 真实化前置依赖 |
|---|---|---|
| 图像/视频生成 | Stub Provider（SVG 占位关键帧/占位帧序列，含资产水印） | D1：模型供应商签约与配额 |
| TTS / BGM | WAV 静音段 / 占位曲库 | D1 + D3（BGM 版权授权） |
| 支付 | 模拟支付回调（out_trade_no 幂等已验证） | D2：支付渠道开通与主体资质 |
| 短信 | 开发模式固定验证码（dev_code 回填） | 短信服务商接入 |
| 微信登录 | `/auth/wechat` Sandbox Stub | 微信开放平台资质 |
| 平台分发 | Stub OAuth + 模拟上传（external_video_id/publish_url 为 demo 值） | 平台 OpenAPI 权限 |
| 内容安全审核 | 规则引擎 + Stub | D4：审核服务接入 |

**结论**：MVP 验收结论在 Sandbox 范围内有效；M1–M13 成功指标（如角色一致性≥95%、成本偏差≤15%）在 Stub 环境仅机制层面验证，真实模型接入后须重新标定与复测。

## 七、遗留事项与风险

### 7.1 需决策事项

1. **LangGraph 编排路线**：资产/分镜/渲染/后期/发行 5 个子图未图化（tasks.md Task 6 未完全勾选）。需二选一：补全子图，或正式确认"同步管线"为目标架构并更新 03 文档 ADR。当前断点续跑仅编剧链路真正基于 checkpoint。
2. **埋点体系**：PRD 第 9 章埋点清单未实现，北极星指标 CCCR 与 M1–M13 无法观测，MVP 上线验证失效风险。

### 7.2 风险清单

| 等级 | 风险 | 应对 |
|---|---|---|
| 🔴 阻塞 | D1 媒体模型未接入——产品核心价值（真实成片）未达成 | 网关已留真实供应商扩展点，签约后按能力逐个替换 |
| 🔴 阻塞 | D2 支付 / D4 审核 / 短信 / 微信未真实化 | 商业化与合规上线前必须完成 |
| 🟡 高 | 进程内 EventBus / asyncio 执行器 / 本地磁盘 → 仅支持单实例 | 生产部署需引入 Redis 与对象存储（03 文档已有方案） |
| 🟡 高 | 真实模型接入后 QC 阈值（0.80/0.68）与成本预估基线需重新标定 | 保留阈值配置在 system_configs，可运营侧调整 |
| 🟢 中 | 非 functional 验证缺失（P95 压测、可用性演练） | 规模化前补充 |
| 🟢 中 | PRD 第 12 章 8 个阻塞级待拍板问题按默认取值实现 | 上线前业务方复核 |
