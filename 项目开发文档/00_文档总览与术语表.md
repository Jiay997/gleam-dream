### 2.1 关键架构决策（ADR 摘要）

| 编号 | 决策 | 结论 | 理由摘要 |
|---|---|---|---|
| ADR-01 | 任务队列 | 用 Celery + Redis，不用 Kafka | 峰值并发在千级任务量内，Kafka 运维成本 > 收益；后续超 5 万并发再评估 |
| ADR-02 | 主键类型 | `BIGINT IDENTITY` 自增主键 | 索引体积小、调试直观、API 路径短；越权由 JWT + ACL 兜底，不依赖主键不可猜 |
| ADR-03 | 幂等键 | `project_id + node_name + input_hash` 三元组落 `idempotency_keys` | 支持重跑不重复扣费 |
| ADR-04 | HITL 实现 | LangGraph `interrupt()` + `approval_requests` 表双写 | 图状态可恢复，业务可查询待办 |
| ADR-05 | 一致性方案 | 资产锚点（`asset_id` → 三视图条件图）而非纯 prompt | prompt 漂移不可控，锚点可复现 |
| ADR-06 | 计费位置 | LangGraph 确定性节点，LLM 不接触扣费 | 避免模型幻觉导致资金错误 |
| ADR-07 | 模型路由 | 确定性代码查表，LLM 只给建议 | 同上 |
| ADR-08 | 前端画布 | Konva 而非 DOM 拖拽 | 百级镜头 DOM 拖拽性能不足 |

### 3.3 Agent 与工程域

| 中文术语 | 英文 / 键名 | 定义 | 易混淆点 |
|---|---|---|---|
| 编排器 | Orchestrator | LangGraph 图本体（非 LLM），负责路由/状态机/中断/计费守卫 | 不是 Agent |
| Agent | Agent | 由 DeepAgents `create_deep_agent` 创建的 LLM 运行时 | — |
| 子代理 | Subagent | Agent 派生的一次性子任务执行体（如按集派生） | 与"子图"不同 |
| 子图 | Subgraph | LangGraph 中嵌套的 `StateGraph` | — |
| 节点 | Node | 图中的一个执行单元，分确定性节点与 LLM 节点 | — |
| 虚拟文件系统 | Virtual FS (`/project/`) | Agent 之间唯一的产物交换介质 | 落库索引为 `project_files` |
| 工作区 | Workspace | 一个项目对应一个 `/project/<project_id>/` 目录 | — |

| 断点续跑 | Checkpoint Resume | 从 LangGraph checkpoint 恢复图状态 | 回滚也用它 |
| 输出契约 | Output Contract | Agent 必须返回的 JSON Schema | 非法输出由校验节点打回 |
| 模型网关 | Model Gateway | 统一封装三方模型调用的适配层 | — |
| 模型路由 | Model Route | 按质量分/价格/排队时长确定选模型（确定性） | LLM 不决策 |

### 3.4 状态与流程域

| 中文术语 | 英文 / 键名 | 定义 |
|---|---|---|
| 幂等 | Idempotent | 同输入重复执行不产生额外副作用 |
| 快照 | Snapshot | 项目状态的某一时刻副本，上限 30 个 |
| 回滚 | Rollback | 用历史 checkpoint 恢复项目状态 |
| 锁 | Lock | 镜头/资产/剧本确认后的不可变状态 |
| 解锁 | Unlock | 上游变更导致下游需重新处理的状态回退 |
| 审计日志 | Audit Log | 越权、敏感操作的不可篡改记录 |
| 操作日志 | Operation Log | 常规 who/when/what 留痕 |

## 四、命名规范（强制）

### 4.1 数据库

| 对象 | 规范 | 示例 |
|---|---|---|
| 表名 | 小写 + 下划线，**复数形式**，不加前缀 | `projects`、`render_tasks` |
| 字段名 | 小写下划线，`snake_case` | `created_at`、`estimated_cost` |
| 主键 | 统一 `id`，`BIGINT GENERATED ALWAYS AS IDENTITY` | — |
| 外键 | `<单数表名>_id` | `project_id`、`shot_id` |
| 布尔字段 | `is_` / `has_` 前缀 | `is_deleted`、`has_watermark` |
| 时间字段 | 后缀 `_at`，统一 `TIMESTAMPTZ`，DB 存 UTC | `approved_at` |
| 金额/积分 | 整数存"最小单位"，后缀 `_credits` / `_amount_cents` | `frozen_credits` |
| 枚举字段 | 存 `VARCHAR(32)`，值用 `snake_case`，不用 PG enum 类型 | `status = 'pending_review'` |
| 软删除 | 统一 `deleted_at TIMESTAMPTZ NULL` | — |
| 审计字段 | 每表必有 `created_at` / `updated_at` | — |
| 索引 | `idx_<表>_<字段列表>` | `idx_shots_storyboard_id_order_index` |
| 唯一约束 | `uq_<表>_<字段列表>` | `uq_users_phone` |

> **枚举落库原则**：一律 `VARCHAR` + 应用层校验 + DB `CHECK` 约束，便于新增取值时不锁表。

### 4.2 API

| 对象 | 规范 | 示例 |
|---|---|---|
| 前缀 | `/api/v1` | `/api/v1/projects` |
| 资源名 | 复数、kebab-case | `/api/v1/render-tasks` |
| 路径参数 | `snake_case` | `/api/v1/projects/{project_id}` |
| 查询参数 | `snake_case` | `?page_size=20&sort=-created_at` |

| 幂等写 | 需 `Idempotency-Key` 请求头 | 支付、生成 |

### 4.3 前端

## 八、全局 API 约定

### 8.1 统一响应包络

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "request_id": "01J9Z8K3M2N4P5Q6R7S8T9V0W1"
}
```

- `code = 0` 表示业务成功；非 0 见错误码段。
- HTTP 状态码语义与业务码解耦：业务失败一般仍返回 200/400，**鉴权失败返回 401/403**，**限流返回 429**。
- `request_id` 每请求生成（ULID），贯穿日志与 Agent trace。

### 8.2 分页约定

| 参数 | 说明 | 默认 |
|---|---|---|
| `page` | 页码，从 1 起 | 1 |
| `page_size` | 每页条数，1–100 | 20 |
| `sort` | 排序字段，`-` 前缀降序 | `-created_at` |

响应 `data`：`{ "items": [], "page": 1, "page_size": 20, "total": 137 }`

### 8.3 错误码段

| 段位 | 领域 | 示例 |
|---|---|---|
| `0` | 成功 | `0` |
| `10000–19999` | 通用/系统 | `10001` 参数校验失败、`10002` 资源不存在、`10003` 服务内部错误、`10004` 请求过于频繁 |
| `20000–29999` | 认证与授权 | `20001` 未登录、`20002` token 过期、`20003` 无权限、`20004` 账号被封禁 |
| `30000–39999` | 计费 | `30001` 积分不足、`30002` 预算超限、`30003` 订单已支付、`30004` 支付回调签名错误、`30005` 冻结记录不存在 |
| `40000–49999` | 项目与剧本 | `40001` 项目状态不允许该操作、`40002` 剧本结构校验失败、`40003` 解析置信度过低、`40004` 项目已归档 |
| `50000–59999` | 资产 | `50001` 资产未锁定、`50002` 人脸相似度过低、`50003` 未完成真人授权、`50004` 上传文件非法 |
| `60000–69999` | 分镜与生成 | `60001` 分镜未锁定、`60002` 任务不存在、`60003` 质检未通过、`60004` 重试次数超限、`60005` 资产锚点缺失 |
| `70000–79999` | 后期与导出 | `70001` 音画同步不达标、`70002` 导出参数非法、`70003` 权益不足（如 4K） |
| `80000–89999` | 外部依赖 | `80001` 模型不可用、`80002` 三方审核失败、`80003` 存储服务异常、`80004` 支付网关异常 |
| `90000–99999` | 管理后台 | `90001` 配置冲突、`90002` 敏感词库导入失败 |
