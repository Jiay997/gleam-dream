# GleamDream Studio 百炼（AI 漫剧）模型接入说明

> 日期：2026-10-21　状态：图片/视频已真实连通，TTS 待解（详见 §7）

## 1. 接入概述

按照 ADR-07 模型网关架构，新增 `bailian` 提供商接入阿里云百炼（AI 漫剧专属推理端点）三类媒体生成能力，替换原沙箱占位（Stub）成为对应任务类型的第一优先路由：

| 能力 | 百炼模型 | 协议 | 状态 |
| --- | --- | --- | --- |
| 语音合成 TTS | `qwen-audio-3.1-tts-plus` | DashScope WebSocket（duplex） | ❌ 引擎 411（待解） |
| 文生图/图生图 | `qwen-image-3.0` | DashScope HTTP 同步多模态生成 | ✅ 已连通 |
| 文生视频/图生视频 | `wan3.0-video` | DashScope HTTP 异步任务 + 轮询 | ✅ 已连通 |

- BGM 能力仍由 Stub 提供商承担（百炼工作区未提供 BGM 模型）。
- LLM 文本生成不受影响（DeepSeek / GLM 走各自提供商）。

## 3. 提供商实现（backend/app/infra/model_gateway/bailian.py）

`BailianProvider(ModelProvider)`，`supports()` 返回 `{image, video, tts}`，注册于 [gateway.py](file:///e:/FeiSi/Project%20code/gleam-dream/backend/app/infra/model_gateway/gateway.py) 的 `_providers["bailian"]`。失败统一以 `GenResult(ok=False, error=...)` 表达（不抛异常），与网关契约一致；所有意外异常在 `generate()` 顶层兜底转失败结果。

### 3.1 TTS（WebSocket duplex）

流程：`run-task`（streaming=duplex，parameters 含 voice/format=wav/sample_rate=16000）→ 收 `task-started` → `continue-task` 提交 `input.text` → `finish-task` 收口 → 持续收集二进制音频帧 → `task-finished` → WAV 落盘 `bailian/audio/*.wav`，meta 含估算 `duration_ms`。

### 3.2 图片（HTTP 同步）

`POST /api/v1/services/aigc/multimodal-generation/generation`，`input.messages` 消息体 + `parameters.size`（如 `1024*1024`）；兼容两种响应形态（`output.choices[0].message.content[*].image` 与 `output.results[*].url`）提取图片 URL，下载落盘 `bailian/images/*.png|jpg`。

### 3.3 视频（HTTP 异步轮询）

`POST /api/v1/services/aigc/video-generation/video-synthesis`（`X-DashScope-Async: enable`）→ 取 `output.task_id` → 每 5s 轮询 `GET /api/v1/tasks/{task_id}` 至 `SUCCEEDED`（超时 600s）→ 下载 `video_url` 落盘 `bailian/videos/*.mp4`。`params.duration_ms` 映射为 `parameters.duration`（4~10 秒档位）；`params.img_url` 支持图生视频。

## 4. 路由与计费（backend/scripts/seed_bailian.py）

幂等种子脚本，负责三张表：

- **model_registry**（3 行）：

| model_key | model_name | capability | unit | 单价（积分） |
| --- | --- | --- | --- | --- |
| bailian-tts | Qwen Audio TTS Plus（百炼语音合成） | tts | per_second | 2 |
| bailian-image | Qwen Image 3.0（百炼文生图） | image | per_image | 15 |
| bailian-video | **Wan 3.0（百炼视频生成）** | video | per_second | 40 |

- **model_routes**（12 行，5 种任务类型）：`text_to_image` / `image_to_image` / `text_to_video` / `image_to_video` / `tts` 的 priority 1 均为百炼模型（非兜底），stub 降为 priority 2 兜底；百炼调用失败时网关按优先级自动降级到 Stub，保证业务链路不断。
- **price_rules**（5 行）：unit 从 model_registry 取，避免 NotNullViolation。

重跑方式（幂等）：

```powershell
backend\.venv\Scripts\python.exe backend\scripts\seed_bailian.py
```

## 6. 与业务链路的集成点

- 渲染任务（render_tasks）按 `task_type` 经 model_routes 命中百炼模型，走既有冻结-结算流程（AiCallLog 记账、trace_id 透传）。
- 分镜出图（text_to_image / image_to_image）、镜头出片（text_to_video / image_to_video）、台词配音（tts）无需任何业务代码改动，即路由切换。
- 百炼失败自动降级 Stub（meta.simulated=true），前端可依据 meta 识别占位产物。
- 视频为异步任务（实测 2~3 分钟），渲染任务器已有轮询/重试语义承载。

## 7. 已知问题与后续事项

1. **TTS 引擎 411（未解）**：WebSocket 握手、run-task/task-started/continue-task/finish-task 事件流全部正常，但 speak 阶段引擎报 `Engine error [411]: TTS speak operation failed`。已矩阵化排除音色（Cherry/longxiaochun/Chelsie/Alfred/toLove）、格式（wav/mp3）、采样率（16k/22k/24k）、流式模式（duplex/out）组合，均 411。初步判断该 AI 漫剧专属工作区的 `qwen-audio-3.1-tts-plus` 不接受公开通用音色名，**需要该工作区的合法音色名列表或官方示例调用**（用户提供后即可修复，协议骨架无需改动）。
2. 视频单价 40 积分/秒为配置值，与百炼侧真实计费无直接换算关系（沙箱积分体系），可按运营需要调整 seed。
3. `wan3.0-video` 与 `wan3.0-video-prime` 切换仅改 `.env` + 重跑 seed 即可，切换后需重启后端生效。
