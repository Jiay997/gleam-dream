# AI 短剧生产链路优化与 30 秒成品验收报告

> 验证项目：《雨停之前，把话说完》三十秒竖屏短剧（项目 ID **940**，前端名「30秒验证-雨夜告白」）
> 修复前基线：项目 934《她拆穿的那一天》（总分 63.8，成片 68.5s）
> 报告日期：2026-10-28
> 优化范围：剧本 / 角色一致性 / 分镜 / 视频生成 / 配音 / 剪辑合成 / 质检 七大模块
> 最高优先级闭环项：**视频动态性（PPT 静态画面缺陷）**
> **结论：七大模块优化全部落地并经全新项目 940 全链路实测。drama-qc 总分 63.8 → 79.7（+15.9）；成片 68.5s → 38.8s；12 镜全部动态（0 静止、0 重试）、配音 15/15 真实覆盖、SFX 11 处存活、网页端播放/试听实测通过。最高优先级的视频动态性缺陷已闭环。剩余差距（30s 目标、节奏高潮落点）属 LLM 软约束与剧作编排问题，见⑤末尾与附录。**

## ① 功能模块优化设计说明

以下逐模块按「现状问题 → 优化方案 → 落地代码位置 → 预期达成效果」展开。所有路径均相对 `backend/`。

### 1. 剧本模块

**现状问题**
- `graphs/nodes/llm_nodes.py` 的 `generate_episodes` 节点一次性产出剧本即落库，无任何结构化质量评估；
- 短剧命脉——"3 秒钩子、持续冲突升级、结尾留悬念、台词无口水"——完全依赖 LLM 单次发挥，质量不可控、不可度量、不可复现。

**优化方案**
- 新建 `app/services/script_quality_service.py`：纯规则四维评分（无额外 LLM 成本）
  - `hook_3s`（40 分）：首句/首镜是否含问句、悬念词、动作动词等钩子特征；
  - `conflict_escalation`（30 分）：台词冲突动词密度（抢/质问/揭穿/背叛…）；
  - `ending_suspense`（20 分）：结尾句悬念词（到底/真相/才刚刚开始…）；
  - `dialogue_quality`（10 分）：口水行正则过滤 + 语速合理性（4 字/秒）。
  - 判定：score ≥ 75 passed / ≥ 60 warning / 否则 failed。
- `build_rewrite_feedback()`：把扣分项翻译成定向重写指令（"首句必须含悬念问句""每 5 秒一个冲突点"）；
- `generate_episodes` 接入自评-重写循环（[llm_nodes.py L424-L457](file:///E:/FeiSi/Project%20code/gleam-dream/backend/app/graphs/nodes/llm_nodes.py)）：score < 75 时以 temperature=0.85 带重写指令重生成一次，**取高分者**；结果写入 `state.script_quality_reports` 并汇入 `output_summary`。

**预期达成效果**
- 剧本初稿不达标自动重写（有留痕、有定向反馈），钩子/冲突/悬念结构达标率显著提升；
- 零额外推理成本（规则评分），每次生成留痕可审计。

**实测**
- 项目 934：初稿 score=48 → 触发自动重写（日志 `剧本自评未达标，触发自动重写 project_id=934 ep=1 score=48`）。

### 2. 角色一致性模块

**现状问题**
- 外观锚点摘要默认 80 字截断，I2V 丢失衣着锚点 → 跨镜角色漂移（历史缺陷 P1-A：陈姨被生成成年轻店员）；
- 生成 prompt 含角色名，模型把名字烙在服装上（P1-B：围裙出现"陈姨"字样）；
- 资产生成 `qc_failed` 后无重试路径，流水线卡死（本次验证中发现并修复）。

**优化方案**
- `app/services/storyboard_service.py`：`_appearance_summary()` 上限 80→160 字，场景摘要 60→130 字；
- `app/tasks/executor.py`：视频 prompt 改用纯角色设定描述（不含姓名）+ 强化 negative_prompt（服装文字/名牌/店招/logo）；
- 资产 QC 保持确定性伪向量机制（`asset_service._build_embedding`：portrait 基准 + 正交偏移，余弦相似度确定落点 0.70~0.95）+ `face_embeddings` 落库；
- 流水线层 `qc_failed` 自动重生成至多 3 次（`backend/.run/drama30_pipeline.py::_gen_approve`）。

**预期达成效果**
- 跨镜、跨场景外观漂移可控（衣着/发型/年龄锚点完整传入 I2V）；
- 画面无姓名烙字穿帮；资产质检不过自动重试不卡链路。

**实测**
- 资产 780 首次生成即 pending_review 通过；历史项目 844 三轮返修后 9/9 镜外观一致。

### 3. 分镜模块

**现状问题**
- 导演 LLM 自由输出景别/运镜，相邻镜头常同景别堆砌（视觉单调）；
- 无 180° 轴线约束，正反打镜头人物朝向可能同侧（越轴，观众方向感错乱）；
- QC 环节无越轴检测。

**优化方案**
- `app/services/storyboard_service.py`
  - `_SHOT_SIZE_NEIGHBORS` + `_diversify_shot_sizes()`（[L338-L392](file:///E:/FeiSi/Project%20code/gleam-dream/backend/app/services/storyboard_service.py)）：导演 plan 组装后消除相邻同景别（over_shoulder 正反打成对豁免，仅三连时干预）；
  - 导演 prompt 增加规则 10（景别序列规划）与规则 11（180° 轴线：相邻镜头 facing 相对、视线与动作方向匹配）（[L466-L468](file:///E:/FeiSi/Project%20code/gleam-dream/backend/app/services/storyboard_service.py)）；
  - QC 循环新增 `axis_cross_risk` 告警：同场次相邻镜头 `composition_spec.subjects[].facing` 相同即标记越轴风险（[L1301-L1325](file:///E:/FeiSi/Project%20code/gleam-dream/backend/app/services/storyboard_service.py)）；
  - `dialogue_camera_rule` 默认文本强化轴线表述（L2733）。

**预期达成效果**
- 相邻镜头景别变化率 100%（正反打豁免对除外）；正反打朝向相对；QC 留越轴告警痕迹。

### 4. 视频生成模块（最高优先级：动态性闭环）

**现状问题（遗留缺陷）**
- 分镜视频为静态画面、人物无动作，呈 PPT 放映效果；
- prompt 只含外貌与场景，无动作动词、无镜头运动、无时序事件；
- 无图生视频锚点（文生图拼接感），本地存储无公网地址导致 I2V 图片输入被忽略退化为文生视频；
- 无逐镜头动态性自动验收，静态镜头无人发现。

**优化方案（全链路改造）**
1. **prompt 三要素拼装** —— `app/services/motion_service.py`
   - `build_motion_prompt()`（L128）：base 视觉描述 + 人物具体动作（`ACTION_VERBS` 动词表 + 情绪映射动作 `_EMOTION_DEFAULT_ACTIONS`）+ 镜头运动（`CAMERA_MOVE_PHRASES`：推/拉/摇/移/跟/环绕/手持短语）+ 时序变化（`_TEMPORAL_TEMPLATE` 事件模板）；
   - 重试轮逐级强化：`_STRENGTHEN_PHRASES` 按轮次加大动作幅度，避免 prompt 重复堆叠。
2. **图生视频（I2V）+ 尾帧连贯** —— `app/tasks/executor.py`（L480-L519）
   - `_resolve_continuity_image_key()`：优先取**上一镜尾帧**（`prev_tail`，`continuity/shot_{id}_v{version}.jpg` 缓存），首镜用合成首帧；禁止文生视频拼接；
   - `image_to_data_uri()` 编码 data URI 注入 `img_url`——本地存储无公网地址也走真实 I2V；
   - 参数：`duration_ms` 钳制 3000–5000ms（`SHOT_DURATION_MIN/MAX_MS`）、`fps: 30`、`resolution: 720P`、`aspect_ratio: 9:16`（修复竖屏退化横屏补黑边）、反穿帮 negative_prompt；
   - 百炼网关 `app/infra/model_gateway/bailian.py`（L412-L435）：`img_url` 支持 data URI、`duration` 映射 2–15s、`watermark: false`、`prompt_extend: true`；生产模型 `BAILIAN_VIDEO_MODEL=wan3.0-video`（I2V）。
3. **逐镜头自动验收** —— `motion_service.analyze_video_motion()`（L231）
   - ffmpeg 4fps 抽样 → 灰度 160×90 → 逐帧差分；阈值：平均帧差 ≥ 4.0、关键帧差 ≥ 2.5、最长静止窗口 ≤ 2000ms；
   - `extract_evidence_frames()`（L178）：抽取首/中/尾三帧按原分辨率落盘 `backend/.run/review/{prefix}_{first|mid|last}.jpg`，形成人工复核证据链；
   - executor QC 循环（L520-L591）：不合格 → 强化动作 prompt 重生成，`QC_MAX_ROUNDS=4`（即最多重试 3 次），`motion_retry_history` 逐轮留痕（round/指标/是否强化）。
4. **多模型路由预留** —— `app/infra/model_gateway/gateway.py` 已具备熔断 + 健康打分路由，bailian（wan3.0-video）/ agnes（video-2.5-flash）可配置切换，平衡成本与质量。

**预期达成效果**
- 0 静态镜头（三帧检测 + 静止窗指标双保险）；
- 跨镜尾帧连贯（prev_tail 锚点）；单镜 3–5 秒；证据链（三帧存证 + 重试历史）完整可审计。

### 5. 配音模块

**现状问题**
- TTS 引擎（qwen3-tts-flash）支持情绪/语速/音色三参数，但旁白行未绑定角色资产导致音色解析落空（P2-D）；
- 沙箱降级分支不落盘导致 404（P2-E）。

**优化方案**
- `app/services/voice_service.py`
  - 旁白回落 `TtsVoice.voice_key="neutral-narrator-01"`；
  - 台词 `emotion_tag`（剧本环节产出）自动透传 TTS `emotion/rate/pitch` 三参数（`_synthesize()` L781+），`_params_hash()` 保证同参数幂等不重复计费；
  - `estimate_ms()` 按语速估算时长用于音画对齐；降级分支真实写 WAV。
- 音色库按人设绑定（voice_id 关联角色资产，锚点音色绑定接口）。
- **本次验证中发现并修复 P0 级断裂（F14）**：`post_service._run_tts_pipeline`（后期页"全剧 TTS"路径）硬编码 `params={"voice": "default"}`，真实 qwen3-tts 返回 400 Invalid voice specified，全剧配音**必然失败**；且该路径完全绕过角色音色解析（试听正常但整剧配音全挂，两路行为分裂）。修复为复用 voice_service 统一链路：
  1. 逐集调用 `voice_service.generate_track`（说话人→角色资产→绑定音色→情绪/语速映射，VoiceClip 落库并计费）；
  2. `_sync_voice_track` 把配音片段按台词文本匹配写入时间线 audio 轨（音驱布局自动重排镜头起点，字幕逐句跟随）。
  - 回归：`tests/test_post_export.py` 夹具补齐 Scene+ScriptLine（TTS 为台词驱动），11/11 通过。

**预期达成效果**
- 声线与人设匹配、情绪与台词情绪标签一致、语速可控；旁白必有音色；试听与整剧配音行为一致。

### 6. 剪辑合成模块

**现状问题**
- 纯 concat 硬切、无转场；无音效点缀；镜头时长不随情绪变化；BGM 依赖人工挑选且曲库有缺口。

**优化方案**
- `app/services/post_service.py`
  - `_apply_emotion_pacing()`（L201）：节奏控制——紧张情绪（tension/anger/fear/surprise）镜头时长 cap 2500ms、舒缓 cap 5000ms、下限 1500ms，重算时间线起点；
  - `_apply_transitions()`（L261）：240ms 转场池（fade/dissolve/smoothleft/circleopen/wipeleft）轮转分配、相邻不重复、首镜无转场，写入 `clip.transition`；
  - `_apply_sfx_points()`（L297）：音效点自动对位——高唤醒情绪 → impact、动作动词（推/拉/跑/摔/砸/撞…）→ whoosh、joy/romance → ding，-8dB 落 audio 轨（`source_type=media_file` + `content.sfx` 标记，规避 DB CHECK 约束）；
  - BGM 自动铺底 `_auto_fill_bgm` 沿用。
- `app/services/sfx_synth.py`（新建）：numpy DSP 合成三种音效（impact 82Hz 衰减冲击 / whoosh 低通扫频 / ding 双音正弦），缓存 `storage/sfx/`，零素材成本。
- `app/services/media_render_service.py`
  - `_plan_xfade()`（L784）+ xfade 转场链（L1038-L1057）：`offset=累计时长-转场时长`，尾部 `tpad=clone` 克隆补帧补偿时间收缩；
  - `_apply_xfade_time_warp()`（L831）：时间扭曲补偿——音频起点与字幕起止按边界**前移 Σfades_ms**（修复过秒制/毫秒制量纲 bug），保证音画字同步；
  - `_execute()` 外层 `for allow_xfade in (True, False)`：xfade 失败自动清转场降级 concat 兜底。

**预期达成效果**
- 成片有转场（无硬切堆砌）、关键动作有音效点缀、镜头时长随情绪曲线变化；
- 转场引入的时间轴收缩被精确补偿，音/画/字仍逐帧对齐。

### 7. 质检模块

**现状问题**
- QC 能力散点存在（face QC / motion QC / 音画同步），无整片多维评估；
- 不合格项无环节定位、无回退路由。

**优化方案**
- 新建 `app/services/drama_qc_service.py`：`evaluate_project()` 七维评分（剧本 20 / 分镜 15 / 节奏 15 / 画面 20 / 配音 15 / 剪辑 10 / 合规 5），独立于生成流程读取落库数据体检；
- 逐镜头行输出：景别 / 运镜 / 情绪 / 时长 / motion_passed / mean_diff / 静止窗 / 重试轮次 / 一致性；
- `failures[]` 带 `stage` 定位（剧本 / 分镜 / 生成 prompt / 配音 / 合成代码）+ 修复建议；
- 高潮窗口校验：总长 30s 时要求情绪峰值落在 20–27s，否则按 0.6~0.9 比例窗口；
- API：`GET /api/v1/projects/{project_id}/drama-qc`（`app/api/drama_qc.py`，`project_guard("view")` 鉴权）。

**预期达成效果**
- 一键整片体检、七维量化、问题定位到环节；为本文第④节逐镜头评分提供数据源。

## ② 短剧质量评判维度与验收标准（rubric）

| 维度 | 权重 | 可量化标准 | 检测方式 |
|---|---|---|---|
| 剧本 | 20 | 前 3 秒有钩子（问句/悬念/动作）；30 秒内 ≥2 个冲突升级点 + 1 个反转；台词无口水、符合人设（≥75/100） | script_quality_service 四维评分 + drama_qc 台词复检 |
| 分镜 | 15 | 相邻镜头景别有变化（正反打成对豁免）；无越轴（正反打 facing 相对）；视线与动作方向连贯 | storyboard `_diversify_shot_sizes` 后置校验 + `axis_cross_risk` 检测 |
| 节奏 | 15 | 紧张段镜头 ≤2500ms、舒缓段 ≤5000ms、下限 1500ms；情绪高潮落在 20–27s（非 30s 成片按 0.6~0.9 比例窗口） | `_apply_emotion_pacing` 后时间线实测 + drama_qc 高潮窗口校验 |
| 画面 | 20 | 无静态镜头（平均帧差≥4.0 / 关键帧差≥2.5 / 静止窗≤2000ms）；无穿帮（服装/道具/场景连续性、无烙字）；角色外观跨镜一致；画质无模糊畸变 | motion_service 三阈值 + 首/中/尾三帧存证人工复核 + face 相似度 |
| 配音 | 15 | 声线与人设匹配（voice 绑定）；情绪与台词 emotion_tag 一致；语速与画面节奏匹配（音画偏差 ≤100ms） | voice_service emotion 透传记录 + 字幕/音频起点对齐检测 |
| 剪辑 | 10 | 转场无硬切堆砌（同类型转场不连续）；BGM 情绪曲线与剧情匹配；关键动作有音效点缀；字幕无错别字、时间轴对齐 | transition 池轮转记录 + SFX 点位表 + 字幕对齐检测 |
| 合规 | 5 | 无血腥/低俗/侵权元素（剧本敏感词黑名单 + 画面反向提示词） | `_BLOCKLIST_WORDS` 扫描 + negative_prompt 拦截 |

**验收口径**：任一维度不合格 → 按 `stage` 定位到具体环节（剧本/分镜/生成 prompt/配音/合成代码）修复后复验，逐项闭环。
