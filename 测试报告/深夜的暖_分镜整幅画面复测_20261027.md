## 六、本轮发现并修复的缺陷

| # | 缺陷 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | 合成画面出现"双重曝光/鬼影"，两人重叠且半透明 | ① `colorkey` 相似度 0.14 抠不掉白墙棚拍的浅灰阴影；② 方形定妆照按屏高缩放横向溢出，双人 x=0.34/0.66 重叠 14% 画布宽 | 相似度提到 0.40；新增**人物宽度上限**（主 46% / 次 42% / 道具 28% 画布宽）；双人位置拉开到 0.28/0.72 |
| 2 | 抠像残留白边（人脸/颈侧白斑） | 素材本身是白墙棚拍 + 浅灰阴影，非纯白底 | 已是最优参数（实测 0.55 会把面部抠穿，0.70 更差）；**遗留**，见第七节 |
| 3 | `colorkey` 直接作用于 rgb24 PNG 时 ffmpeg 退出 -5 | 抠像需要 alpha 通道，PNG 常为 rgb24 | 滤镜前置 `format=rgba` |
| 4 | 抠像覆盖率恒为 0，导致所有素材误判为"抠像失败→卡片排版" | `metadata=print` 输出通道随版本变化（本次在 stderr） | 合并解析 stdout+stderr |
| 5 | 重渲染后成片画面不变 | `compose` 只比较 video 片段**数量**，数量一致即复用旧片段，不校验版本 | 有效性判定加"每个片段 source_id 必须等于该镜头当前版本"，不一致即重铺 |
| 6 | 分镜道具从未参与画面 | `prop_asset_ids` 恒为空，取图永远命中不到道具 | LLM 契约新增 `prop_names`，生成时优先按名称绑定，文本匹配兜底 |

## 七、遗留问题与改进方向

| 级别 | 问题 | 影响 | 改进方向 |
| --- | --- | --- | --- |
| P1 | 抠像边缘残影（白斑）仍在 | 画面"贴上去"的痕迹明显，影响成片观感 | ① 资产侧做一次**白底净化**（去阴影、提纯背景）；② 开通方案 B：多图参考模型精修（约 0.2–0.5 元/张，10 镜≈2–5 元） |
| P1 | 场景图内自带人物（收银员）与置入角色并存 | 同一空间出现"多余演员"，语义拥挤 | 分镜生成时为场景镜优先使用**空景场景资产**；或在 spec 增加 `avoid_regions` 遮挡 |
| P2 | 道具镜（镜 10）未绑定道具 | `prop_asset_ids=None`，画面无纸条 | 该镜 `action_desc` 未出现道具名且 LLM 未给 `prop_names`；补充剧本描述或手工绑定 |
| P2 | `height_ratio` 与实际画面高度不完全一致 | spec 记录的是"上限意图"，宽度约束后实际更小 | 合成后回写 `actual_height_ratio` 到 spec，供 QC/前端展示真实值 |
| P2 | `tests/test_v4_features.py` 29 项失败 | 非本次改动引入：`.env` 中 `SANDBOX_MODE=false` 时 `/auth/sms-code` 不返回 `dev_code` | 测试专用环境改 `SANDBOX_MODE=true`，或测试改用离线签发令牌 |
| P2 | `tests/test_asset_storyboard.py` 1 项失败 | 断言"无锚点锁定应 60005"前提不成立（生成时已自动绑定锚点） | 测试改为显式清空锚点后再断言 |

## 九、结论

1. **"单张图片"问题已解决**：每镜产出 720×1280 的整幅要素画面，场景、角色、道具按构图规则置入，QC 采信度从"伪向量一致性"升级为"要素是否真的出现"。
2. **链路贯通**：合成帧 → 渲染驱动 → 时间线 → 成片，全链路 0 积分、可验证（`poster_key` 与 `source_id` 双重证据）。
3. **尚未达到"可直接上线"的观感**：抠像残影与场景自带人物是当前成片最明显的两处不足，建议按第七节 P1 处理（资产白底净化优先，模型精修为备选）。
