## 三、缺陷清单（按严重性从高到低）

> 严重等级定义：**致命** = 核心业务闭环或核心能力不可用；**严重** = 关键功能错误、数据一致性风险或全量用户可见错误；**一般** = 有替代路径的体验/稳定性问题；**轻微** = 视觉、文案或非阻塞问题。

### P0-01【致命】V4 能力中心「分镜（F4）」内容空白

- **所属模块**：V4 能力中心
- **复现步骤**：
  1. 登录后访问 `http://127.0.0.1:5175/projects/151/v4`，等待页面完全加载；
  2. 点击顶部“分镜（F4）”页签；
  3. 观察内容区，并打开浏览器控制台。
- **预期结果**：展示 PRD V4.0 的分镜能力面板（镜头重排、节奏分析、张力曲线等）。
- **实际结果**：页签已选中，但内容区完全空白，仅保留 V4 页面标题与页签；控制台输出 `Failed to resolve component: StoryboardV4Panel`。
- **证据**：截图 `int2-09-v4-storyboard.png`（页签选中、内容区空白）；日志见 `gd_interact2.json` 的 console 字段。
- **根因定位**：`frontend/src/views/V4CapabilityView.vue` 在模板中使用了 `StoryboardV4Panel`，但 `<script setup>` 未导入该组件；组件文件实际存在于 `frontend/src/components/v4/StoryboardV4Panel.vue`。
- **修复建议**：在 `V4CapabilityView.vue` 中显式 `import StoryboardV4Panel from '@/components/v4/StoryboardV4Panel.vue'`，并逐一核对其余 V4 面板组件的导入；回归验证 6 个能力页签均有内容。

### P0-02【致命】后期合成被音画同步偏差阻断，且同页数据自相矛盾

- **所属模块**：后期编辑器 / 成片导出
- **复现步骤**：
  1. 访问 `http://127.0.0.1:5175/projects/151/post`；
  2. 查看调音台与时间线区域的音画同步提示；
  3. 点击“合成成片 · 母版导出”，查看确认弹窗。
- **预期结果**：已完成项目 151 的音画同步误差应小于 100ms，可正常合成导出；若存在偏差，应提供可执行的修正入口。
- **实际结果**：
  - 页面提示：“⚠ 音画同步：3 处偏差超 100ms（#71 ↔ 配音 1 偏差 17000ms；#69 ↔ 配音 2 偏差 22000ms…）· 合成时后端将拦截（70001）”；
  - 同一页面底部又显示“音画同步误差: 35000ms (< 100ms 达标 ✓)”，两处口径矛盾；
  - 合成确认弹窗明确提示合成会被后端拦截。
- **证据**：截图 `int-10-post-compose.png`（合成确认弹窗与告警）、`post.png`（后期页）；日志文本见本报告附录 A。
- **影响**：项目 151 为已完成项目，成片→终审→导出的商业闭环再次被阻断。
- **修复建议**：
  1. 修正音画同步统计口径（统一使用同一数据源，35000ms 不应标记为“达标”）；
  2. 在后期页提供“一键对齐时间线/重新配音/音频微调”入口，或在前序生成链路保证视频时长与 TTS 音频一致；
  3. 合成前给出可操作的差异清单（镜头号、画面时间、配音时间、差值），而不是仅提示被拦截。

### P1-02【严重】分镜锁定态仍可“自动布局并保存”

- **所属模块**：智能分镜画布
- **复现步骤**：
  1. 访问 `http://127.0.0.1:5175/projects/151/storyboard`，等待加载完成；
  2. 确认页面显示“已锁定 · HITL-3 审批中”“镜头卡片与参数均只读”；
  3. 点击“自动布局”（或“保存布局”）按钮。
- **预期结果**：锁定态下布局编辑应被禁用或提示“审批中不可修改”，不产生保存动作。
- **实际结果**：按钮可点击，并出现成功提示“✓ 布局已保存 / ✓ 已按网格重新排列”，与“只读”约束冲突。
- **证据**：截图 `int-08-shot-click.png`；操作日志 `gd_interact.json` 中步骤 C4 的 toast 原文：“✓ 布局已保存 / ✓ 已按网格重新排列”。
- **影响**：审批中的分镜视图布局可被修改并持久化，存在 HITL 审批一致性与审计风险。
- **修复建议**：在锁定态统一禁用布局类写操作，或将布局调整纳入审批变更记录；后端保存布局接口增加锁定态校验。

### P1-03【严重】工作台首屏弹出“参数校验失败”

- **所属模块**：项目工作台 / 预算消耗
- **复现步骤**：
  1. 登录后进入 `http://127.0.0.1:5175/projects`；
  2. 观察页面右下/顶部 Toast；
  3. 查看网络请求。
- **预期结果**：工作台正常加载，不应出现全局错误提示。
- **实际结果**：首屏出现“参数校验失败”Toast；抓包显示 `GET /api/v1/billing/transactions?page=1&page_size=200&transaction_type=settle` 返回业务错误 `code 10001（参数校验失败）`，后端对 `page_size` 上限为 100。
- **证据**：截图 `projects.png`（Toast）；网络响应日志见 `gd_diag3.json` 的 bad 列表；前端调用位置 `frontend/src/views/ProjectsView.vue:458`。
- **修复建议**：将 `page_size` 调整为 ≤100（或后端放宽限制并统一分页契约），并在 API 层集中校验分页上限，避免各页面各自传入越界值。

### P2-01【一般】登录态恢复竞态导致首屏请求 401

- **所属模块**：全局鉴权 / SSE
- **复现步骤**：
  1. 清除会话后完成密码登录，直接刷新任意项目页；
  2. 观察 Network 与控制台。
- **预期结果**：所有受保护请求均携带有效 `Authorization`，SSE 首次连接成功。
- **实际结果**：首屏出现 `GET /api/v1/billing/credit-account → 401`；项目事件流首次连接 `GET /api/v1/projects/151/events?access_token=` 返回 401，随后重连成功。控制台出现相关错误。
- **证据**：网络日志（见附录 A）；巡检结果 `gd_frontend_result.json` 中 overview/script 页 netFails。
- **修复建议**：应用启动时先 `await` 会话恢复再发起业务请求；SSE 在 token 非空后再建立连接，并在 401 时按退避策略重连而不清空会话。

### P2-02【一般】镜头详情深链接失效

- **所属模块**：分镜画布 / 镜头详情
- **复现步骤**：

### P2-03【一般】关键页面首次访问长时间骨架屏

- **所属模块**：全局性能
- **复现步骤**：冷启动后首次访问计费中心、通知中心、团队、V4、角色详情、分镜画布、分发页。
- **预期结果**：3 秒内出现主体内容或明确的加载进度/超时提示。
- **实际结果**：计费/通知/团队在 5–8 秒内仍为骨架屏；角色详情/分镜/分发首次访问需 10–15 秒才渲染；移动端工作台 5 秒、V4 8 秒仍为骨架。页面无进度百分比或超时说明。
- **证据**：截图 `billing.png`、`resp-projects-375.png`、`v4.png`；巡检 JSON 中对应 `appLen` 与文本为“连接中 / 已完成 / 预算”。
- **说明**：该现象与 Vite 开发态首次编译强相关，生产构建需复测；但“无进度/无超时提示”仍属真实体验问题。
- **修复建议**：生产构建复测并给出性能基线；关键页面增加骨架屏文案（“正在加载资产/分镜…”）与超时重试；路由懒加载预取。

### P2-04【一般】Vue 控制台警告：事件监听无法继承

- **所属模块**：分镜 / 后期
- **复现步骤**：打开分镜画布或后期编辑器，查看控制台。
- **预期结果**：无 Vue 运行时警告。
- **实际结果**：反复出现 `[Vue warn]: Extraneous non-emits event listeners (click, dragend, ...) were passed to component but could not be automatically inherited because component renders fragment or text root nodes.`。
- **证据**：`gd_interact.json` / `gd_interact2.json` 的 console 字段；截图 `int-09-post.png`。
- **影响**：拖拽/点击监听可能丢失，后续拼接交互存在隐患。
- **修复建议**：为 Group 类组件提供单一根节点并显式声明 emits；或在调用处改用显式回调 props。

### P3-01【轻微】移动端面包屑截断、步骤导航仅可横向滚动

- **所属模块**：全局布局（375px）
- **复现步骤**：以 375×812 访问项目内页面。
- **预期结果**：面包屑可读、步骤导航有滚动提示或折叠。
- **实际结果**：顶部面包屑显示为“制… / E2… / 分…”；8 个步骤页签需横向滑动，部分标题被截断；无横向溢出（scrollWidth = innerWidth），主体布局正常。
- **证据**：截图 `resp-storyboard-375.png`、`resp-render-tasks-375.png`。
- **修复建议**：移动端面包屑仅保留当前页/上级，或使用省略号菜单；步骤导航增加左右渐隐/滚动指示。

### C-01【待确认】资产墙“多角色批量重抽”入口

## 六、结论与建议

### 6.1 总体结论

前端 28 个路由页面均可访问，P01–P22 主流程页面与 PRD F1–F8 的核心信息架构基本一致；工作台、剧本、资产、分镜、生成、后期、分发、计费、团队、通知等功能均有完整界面与真实数据。  
但存在 **2 项致命缺陷**（V4 分镜面板空白、后期音画同步阻断导出）与 **3 项严重缺陷**（资产搜索失效、锁定态可保存布局、工作台首屏错误提示），会直接影响 V4 能力交付、成片导出闭环与日常使用体验。

### 6.2 修复优先级建议

| 优先级 | 缺陷 | 建议动作 |
|---|---|---|
| P0 | P0-01 V4 分镜面板 | 导入并注册 `StoryboardV4Panel`，回归 6 个能力页签 |
| P0 | P0-02 音画同步 | 统一同步口径、修正 35000ms 误判、提供一键对齐/重新配音 |
| P1 | P1-01 资产搜索 | 修复 v-model 与过滤 computed，补空态 |
| P1 | P1-02 锁定态布局 | 锁定态禁用保存布局，后端增加状态校验 |
| P1 | P1-03 参数校验失败 | `page_size` 改为 100 或统一分页上限 |
| P2 | P2-01 401 竞态 | 会话恢复前不发请求；SSE 等 token 就绪 |
| P2 | P2-02 镜头深链接 | 保留 `shots/:shotId` 路由状态 |
| P2 | P2-03 首访慢 | 生产构建复测 + 加载进度/超时提示 |
| P2 | P2-04 Vue 警告 | 修复 Group 组件根节点/emits |
| P3 | P3-01/02 | 移动端面包屑与全局搜索占位优化 |
