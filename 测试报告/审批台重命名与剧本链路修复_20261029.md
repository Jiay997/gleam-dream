# 审批台重命名与剧本链路修复记录

| 项目 | 内容 |
|---|---|
| 日期 | 2026-10-29 |
| 范围 | 项目内导航命名、剧本 HITL-1 提交后的跳转、审批单生成与审批台可达性 |
| 验证环境 | 前端 `127.0.0.1:5175`、后端 `127.0.0.1:8100`，测试项目 982（owner 212） |
| 结果 | 命名全链路一致；剧本提交审核后自动创建 HITL-1 审批单并跳转审批台；审批台可见待办并可进入审批详情 |

## 1. 问题与根因

| 问题 | 根因 |
|---|---|
| 菜单项“1 总览”语义不清，用户找不到“审批台” | 项目内导航第一项命名为“总览”，路由 meta 标题也是“项目总览”，页面内无“审批台”身份标识 |
| 点击剧本页“批准剧本并进入资产规划”无跳转 | `submitScriptReview` 只执行合规审核，成功后仅刷新待办数量并 toast，未导航 |
| 审批台看不到待办 / 页面找不到 | ① 手动“提交审核”后端 `submit_script_review` 只把剧本置 `pending_confirm`，**不创建 `ApprovalRequest`**；② 剧本页原“前往审批台确认”直接跳 `/script/review`，该页无待审单时显示空态，用户误以为页面不存在 |

## 2. 修改清单

### 前端

| 文件 | 修改 |

| `frontend/src/views/ScriptEditorView.vue` | 提交按钮文案改为「提交审核 · 前往审批台」；提交成功后 toast 提示并 `router.push` 审批台；合规 block 时留在剧本页并提示修正；`goReview` 统一跳审批台 |
| `frontend/src/views/ScriptReviewView.vue` | 空态按钮“返回项目总览” → “返回审批台”；注释同步 |

### 后端

| 文件 | 修改 |
|---|---|
| `backend/app/services/script_service.py` | 新增 `_ensure_script_approval`：审核通过（`pending_confirm`）时幂等创建 HITL-1 审批单；仅对 `draft/scripting/script_review` 阶段生效，避免回退后续环节；已有 pending 单时复用并指向最新版本 |
| `backend/app/api/scripts.py` | `submit-review` 返回新增 `approval_id`，文档同步 |
