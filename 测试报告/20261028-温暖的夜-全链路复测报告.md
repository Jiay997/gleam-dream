## 2. 成本控制方式

- **本轮实际消耗：1244 积分**（渲染 10×120 = 1200 + TTS 44），护栏 1244/2000（79.1%）。
- 成本控制手段：
  1. **单镜试渲染先行**：先渲 1 镜（任务 678）验证模型连通与动态性，通过后再批量渲 9 镜，避免批量失败浪费冻结额度；
  2. **失效路由停用**：先停用 401 的百炼旧配置行，避免每次任务先撞死 key 消耗重试轮次；
  3. **失败全额返还**：任务失败 0 计费（本次 3 次 Agnes 失败均未扣费）；
  4. **幂等键**：批量渲染/导出均带 Idempotency-Key，防重复扣费；
  5. **时长收紧**：生成 4s、成片时间线裁剪至 3s/镜（3–5s 合规区间下限），按秒计费成本最低档。

## 4. 动态性验收标准与结果（最高优先级）

### 验收标准
1. 每镜生成 prompt 必含三要素：**人物具体动作**（动词描述）+ **镜头运动**（推/拉/摇/移至少一项）+ **时序变化**（画面内事件）；
2. 单镜时长 3–5 秒，最长静止画面 ≤ 2 秒；
3. 使用 **I2V（图生视频）**：上一镜尾帧/本镜合成首帧驱动，禁止逐镜独立文生图拼接；
4. 每镜自动帧差验收：4fps 抽样，灰度像素差 `mean_diff ≥ 4` 判动态，低于阈值触发强化 prompt 重绘（≤3 轮，记录 `motion_retry_history`）。

## 5. 问题定位与修复清单（文件/函数级）

### P0-1 视频模型全线不可用（渲染降级 stub 的根因之一）
- **现象**：百炼 wan3.0-video 401 InvalidApiKey；Agnes video 持续 503 video_queue_full。
- **定位**：`.env` BAILIAN_API_KEY 失效；model_configs 行 222（dashscope-video）指向失效 key。
- **修复**：用户提供 qianwenai 平台新 key。实测该平台 `MiniMax/MiniMax-H3` 返回 `InvalidParameter: product not activated`（产品未开通，需在平台控制台开通）；同平台 `wan2.6-i2v-flash` 可用（720P/1080P，I2V 必传 img_url）。经实测出片+帧差通过后，将行 222 更新为 `api_model=wan2.6-i2v-flash` + 新 key + 启用。
- **验证**：手动 I2V 测试出片（4s 720P，2.3 分钟）；任务 678 重试成功 `degraded=False`、计费 120。

### P0-2 手动重试门槛与批量重试不一致，任务无法重新入队
- **现象**：`batch_retry` 返回 `accepted=[]`，失败任务 678 无法重试。
- **定位**：[render_service.py](file:///e:/FeiSi/Project%20code/gleam-dream/backend/app/services/render_service.py#L1015) `retry_task()` 门槛 `retry_count >= max_retries`（2 次即拦），而同文件 `batch_retry()`（L1703）为 `max_retries + 3`（5 次），两处不一致导致执行器内部 2 次重试耗尽后用户永远无法手动重试。
- **修复**：`retry_task()` 门槛对齐为 `retry_count >= max_retries + 3`，并加注释说明。
- **验证**：重启服务后 batch-retry 正常受理，任务 678 重跑成功。

### P1-3 后端进程无热加载，代码修改不生效
- **定位**：`run_server.py --port 8100` 启动无 `--reload`；修改 bailian.py / render_service.py 后必须重启进程。
- **修复**：重启后端进程（PID 35160 → 新进程）。
- **验证**：`/api/v1/health/models` 探针恢复，任务重新入队成功。

### P2-4 导出权益拦截（70003）
- **现象**：`with_watermark=False` 导出失败：pro 套餐不支持去水印（required_benefit: no_watermark）。
- **修复**：按权益改为 720P+水印导出；系统自动注入 AIGC 合规标识（"本内容由 AI 辅助生成"+ 隐式元数据），符合内容合规要求。
- **验证**：导出任务 158 succeeded，成片 33.92s 可播放。

### 观察项（不阻塞交付）
- **前端音画同步提示**：后期页提示 `#8 ↔ 配音6 偏差 3536ms`（前端 A-B 对齐预检口径），后端合成 QC 未拦截、时间线正常生成。建议后续统一前后端偏差计算口径（post.py QC 阈值 100ms 的适用范围）。
